# Smart Baby Cradle IoT System

## Overview

The Smart Baby Cradle is an IoT-based embedded system designed
to automate baby comfort monitoring using sensors and actuators.

The system detects:
- Baby crying sound
- Room lighting condition

Based on sensor input, the cradle:
- Swings automatically
- Plays lullaby sounds
- Activates LED alerts

## Features

✅ Cry detection  
✅ Automatic cradle movement  
✅ Light-based sleeping mode  
✅ Lullaby generation  
✅ LED notification system

## Hardware Components

- Arduino Uno
- Sound Sensor
- Photoresistor (LDR)
- Servo Motor
- Piezo Buzzer
- LED
- Push Button
- Breadboard

## Technologies Used

- Arduino IDE
- Embedded C/C++
- Sensors & Actuators
- Embedded System Design

## System Workflow

1. Sensors collect environmental data.
2. Arduino processes sensor input.
3. Output devices respond automatically.
